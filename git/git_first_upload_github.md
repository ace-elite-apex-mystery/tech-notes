# 🚀 專案首次上傳到 GitHub 教學

本文件說明如何將本地端已完成的專案推送（push）到 GitHub。

------------------------------------------------------------------------

## 🧭 一次搞懂整個流程

### 🔹 步驟 1：初始化 Git

``` bash
cd /你的專案資料夾路徑
git init
```

建立 `.git` 目錄，開始進行版本控制。

------------------------------------------------------------------------

### 🔹 步驟 2：加入所有檔案到追蹤

``` bash
git add .
```

`.` 代表加入當前資料夾的所有檔案。

------------------------------------------------------------------------

### 🔹 步驟 3：建立第一次提交

``` bash
git commit -m "Initial commit"
```

`-m` 參數後面的字串是提交訊息。

------------------------------------------------------------------------

### 🔹 步驟 4：在 GitHub 建立新 Repository

1.  登入 [GitHub](https://github.com)
2.  點選右上角「➕ → New repository」
3.  輸入專案名稱（例如 `my-project`）
4.  建議：
    -   ✅ 不要勾選「Initialize this repository with a README」
    -   ✅ 保持空白狀態（因為你要從本地推上去）

------------------------------------------------------------------------

### 🔹 步驟 5：連結遠端 GitHub 儲存庫

HTTPS 範例：

``` bash
git remote add origin https://github.com/你的帳號/my-project.git
```

SSH 範例：

``` bash
git remote add origin git@github.com:你的帳號/my-project.git
```

------------------------------------------------------------------------

### 🔹 步驟 6：推送本地分支到 GitHub

``` bash
git branch -M main
git push -u origin main
```

建立遠端追蹤關係。

------------------------------------------------------------------------

### 🔹 步驟 7：（可選）檢查結果

``` bash
git remote -v
```

輸出應類似：

    origin  https://github.com/你的帳號/my-project.git (fetch)
    origin  https://github.com/你的帳號/my-project.git (push)

------------------------------------------------------------------------

## 💡 常見補充

-   若推送時出現權限錯誤：
    -   HTTPS：請使用 GitHub Personal Access Token 當密碼。
    -   SSH：請確認你已設定 SSH key 並加到 GitHub。

------------------------------------------------------------------------

📘 **完成後**：打開你的 GitHub repo 頁面，就能看到專案內容！ 🎉
